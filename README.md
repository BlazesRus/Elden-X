# elden-x

This repo contains miscellaneous C++ utilities Thomas J. Clark uses to write runtime DLL extensions for ELDEN RING. Used in mods such as:

- [Transmogrify Armor](https://www.nexusmods.com/eldenring/mods/3596) by Thomas J. Clark
- [Glorious Merchant](https://www.nexusmods.com/eldenring/mods/5192) by Thomas J. Clark
- [Armor Dyes](https://github.com/ThomasJClark/elden-ring-dyes) by Thomas J. Clark
- [Quest Log](https://www.nexusmods.com/eldenring/mods/3585) by TheEldenRingQuestGiver

If you're looking for a library for DLL modding, consider [eldenring-rs](https://github.com/vswarte/eldenring-rs) or [libER](https://github.com/Dasaav-dsv/libER).

Planned to help convert this for use in the SDK as part of the Game Mod Framework (including the Virtual Record System for ELDEN RING).
